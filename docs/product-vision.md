# Product Vision

USI Hub / UEH Innovation Platform should become an incubation operating system for startup support, program management, knowledge retrieval, and evidence-based recommendations.

The platform should help SGAs, leaders, mentors, trainers, founders, and alumni coordinate around one trusted view of startup progress.

## Core Vision

- Give each startup a structured operating profile.
- Help program teams track milestones, documents, mentoring, workshops, risks, and next actions.
- Turn USI documents into a searchable knowledge base.
- Provide USI Brain as a RAG assistant that cites evidence and highlights missing data.
- Support Vietnam-context evaluation using local market, regulation, customer behavior, mentors, investors, grants, and ecosystem knowledge.

## Non-Negotiable Principles

- AI supports decisions but does not make final decisions.
- AI proposes updates but does not directly write approved platform data.
- Humans approve sensitive recommendations and data changes.
- Founder trust matters. Support spaces should not feel like surveillance.
- Data quality is a product feature, not an afterthought.
