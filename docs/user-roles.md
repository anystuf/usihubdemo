# User Roles

## SGA / Program Team

- Manage startup profiles
- Upload documents
- Record mentor sessions
- Track actions and risks
- Review AI proposals

## Leaders

- View cohort dashboard
- Review reports and risk signals
- Approve strategic decisions
- Monitor platform impact

## Mentors

- View assigned startup context
- Prepare for sessions
- Add notes and recommendations
- Answer founder questions where invited

## Trainers

- Share workshop materials
- Review attendance and feedback
- Link content to Knowledge Base

## Founders

- View own Startup OS
- Update progress
- Ask support questions
- Access approved playbooks and templates

## Alumni

- Answer founder questions
- Join mentor/support loops
- Share practical market experience

## Admin

- Manage roles, permissions, source indexing, and system configuration.
